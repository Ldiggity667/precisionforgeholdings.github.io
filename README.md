# Precision Forge Holdings

This repository contains the static website for Precision Forge Holdings LLC, an engineering software and advanced manufacturing company.

The site is published at [precisionforgeholdings.com](https://precisionforgeholdings.com/) and is built as a single HTML page without a separate build step.

## Repository contents

- `index.html` — company overview, software initiatives, corporate profile, and contact information.
- `CNAME` — custom domain configuration for `precisionforgeholdings.com`.

## Local preview

Open `index.html` in a web browser to preview the site. Edit this file to update the page content or styling.
